# Energieberatung Regio Stolberg – Website (Entwurf)

Statischer Mehrseiter, kein Build-Werkzeug nötig.

- **Ansehen:** `index.html` doppelklicken, oder im Projektordner `python3 -m http.server 8767` starten und http://localhost:8767 öffnen.
- **Ändern:** Texte und Seitenstruktur stehen in `_build.py`. Nach jeder Änderung `python3 _build.py` ausführen, das erzeugt alle HTML-Dateien neu. Gestaltung in `styles.css`, Bewegung in `main.js`.
- **Gestaltungsregeln:** `DESIGN.md`. **Vor dem Online-Stellen:** `LAUNCH-CHECKLISTE.md`.
- **Bildnachweis:** `img/BILDNACHWEIS.md`.
